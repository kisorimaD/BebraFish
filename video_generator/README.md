# Генератор синтетической кальциевой съёмки zebrafish

Генератор строит синтетическую съёмку по выровненным TIFF одного набора.
Одна плоскость задаёт пространственный профиль и параметры изображения.
Трассы кальциевой активности извлекаются из остальных плоскостей и
назначаются новым сомам. Код инференса входит в комплект. Для обработки новых TIFF
подключите свои совместимые веса сегментации.

## Подключение исходного Plane20 Synthetic

Для запуска нужны оба архива. Распакуйте этот архив и зайдите в его
корневую папку. Подключите исходный `plane20_synthetic.zip` и примените
изменения генератора. В Linux нужны команды `unzip` и `patch`.

```bash
unzip -q /path/to/plane20_synthetic.zip -d plane20_synthetic
patch -p1 < plane20_synthetic.patch
```

Данные для повторной отрисовки итоговой синтетики находятся в
[results/Plane20](results/Plane20/README.md). Там же есть пример
восстановления отдельного кадра.

## Установка

Среда для этого комплекта — Linux x86-64 и Python 3.11. Запустите команды
из корневой папки распакованного архива.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-render.txt
```

Для сегментации новых TIFF дополнительно установите зависимости
через `python -m pip install -r requirements.txt`.

Генерация и инференс выполняются на CPU. Для отдельных вариантов
сжатия TIFF может понадобиться `imagecodecs`, совместимый с NumPy 1.26.
Если `imageio-ffmpeg` не находит свой FFmpeg, можно указать
путь к установленному бинарнику через `IMAGEIO_FFMPEG_EXE`.

## Запуск

Входные данные — минимум две выровненные плоскости с именами
`Plane20.tif` или `Plane_Aligned_20.tiff`. Ожидаются 16-битные
одноканальные TIFF-стеки с одним кадром на страницу, одинаковой формой
кадра и одинаковым числом кадров. Минимум 100 кадров на плоскость.
Для подгонки нужно достаточно обнаруживаемых сом как в опорной
плоскости, так и в донорских.

```bash
python analysis/plane20_gcamp8f_response/run_dataset.py \
  --input /path/to/aligned-tiffs \
  --reference-plane 20 \
  --checkpoint /path/to/center-mask-checkpoint \
  --output ./synthetic_run
```

Укажите фактический номер опорной плоскости. По умолчанию читаются все
подходящие TIFF в папке. Для поднабора используйте `--planes 19 20 21`.
Передайте `--fps` с частотой кадров TIFF, если она известна. Иначе для
выбора кадров используется 12,5 кадра/с. Опция `--cells 450` ограничивает
число синтетических сом, а `--seed` задаёт воспроизводимый подбор.
Повтор с теми же аргументами и `--resume` продолжает незавершённый запуск.

Передайте через `--checkpoint` папку с файлами `weights_best.h5` и
`model_config.json` от совместимой модели `plane20-center-mask-v1`.
При необходимости укажите `--model-code` и `--segment-python`.
При переходе на другую оптику или масштаб просмотрите маски в `per_plane/`.

## Результаты

- `per_plane/` содержит центры, маски и извлечённые трассы.
- `foreground/` содержит отфильтрованный банк трасс и оценку согласованности.
- `profile.npz` содержит карты, построенные на опорной плоскости.
- `scene/scene_00000.npz` содержит синтетический статичный рендер, координаты
  сом и массивы масок.
- `render/activity.npz` содержит полные назначенные трассы в порядке
  кадр × сома. `dff` уже учитывает круговые сдвиги. `bank_columns` и
  `shift_frames` позволяют проследить назначение. Для рендеринга
  относительное свечение рассчитывается как `max(0, 1 + dff)` с делением
  на временную медиану для каждой сомы.
- `render/assignments.csv` связывает синтетические сомы с донорскими
  ROI, а `render/generation.json` хранит параметры и метрики на
  отложенных кадрах.
- `render/plane20_recorded_activity.gif` показывает реальную запись
  сверху и синтетику снизу на одной шкале. `plane20_signal_residual.gif`
  добавляет разложение на сигнал и фон с шумом. GIF сохраняются при
  3 кадрах/с и длятся до 60 секунд. Префикс Plane20 сохранён в именах
  файлов для любого номера опорной плоскости.

В комплекте есть данные итогового рендера Plane20. Для нового запуска используйте свои TIFF.
