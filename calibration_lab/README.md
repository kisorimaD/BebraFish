# BebraFish — калибровка 2D-синтетики в браузере

Из корня репозитория:

```bash
python -m pip install -r requirements-analysis.txt
python -m calibration_lab --open
```

Адрес приложения — http://127.0.0.1:8767. Можно задать другой порт через
`--port`. Кнопка «Выбрать TIFF…» открывает системный диалог. Файл передаётся
локальному серверу и после подготовки медианы временная копия удаляется. Поддерживается готовая двумерная медиана и многостраничный TIFF
одной плоскости. Для стека приложение поправляет поступательное смещение
и строит медиану по равномерной выборке до 64 страниц. Номера страниц и
оценённые сдвиги записываются в отчёт.

1. Откройте запись. После подготовки изображения мастер сразу откроет Soma Lab.
2. Обведите около 20 сом по внешнему видимому краю в нескольких участках
   и дождитесь автосохранения. Для подгонки нужны хотя бы пять уверенных
   полных контуров, из них хотя бы три с различимой оболочкой.
3. В Region Lab заливкой отметьте фон и области без сом. Порог относится
   к медиане.
4. В разделе «Центры» выберите несколько участков разной плотности.
   Отметьте все различимые центры и поставьте галочку у каждого
   просмотренного кропа. Пустой просмотренный кроп тоже учитывается.
5. Укажите число сцен и seed. Нажмите «Настроить и сгенерировать».

Калибровка рассчитывает форму, радиальный профиль оболочки, амплитуду
и неоднородность света, приближённый фон и параметры плотности. Когда
контуров недостаточно для оценки яркостной связи между соседями,
используется независимый разброс яркости. Целевое и фактическое число
сом выводятся отдельно, поскольку укладка проверяет допустимость полных
масок. Текущая реализация рассчитана на медианные изображения.

В новых прогонах слой `image_structured` добавляет зерно с амплитудой,
зависящей от яркости. Внутри масок сом используется яркость рендера,
вне масок — сглаженная яркость референса. При импорте стека кривая
оценивается по соседним кадрам и приближённо пересчитывается для медианы
исходя из независимости кадров. Для готового 2D-изображения используется
оценка по пространственным перепадам в блоках 2×2. Метод и значения кривой
записываются в профиль и отчёт. Сохранённые профили без кривой сохраняют
прежний рендер засветки.

## Настройка свечения

После генерации откройте «Настроить свечение» рядом со ссылкой на ZIP.
Выберите кроп из списка или кликните по обзорному кадру. Ползунки меняют
радиус и ширину оболочки, заполнение центра, размытие, яркость и её
разброс. Размеры сом, центры и реализация зерна фиксируются для всех
проб. На графике показан медианный радиальный профиль по сомам, чей
профиль целиком помещается в кроп. Ошибка профиля — RMSE в ADU от
центра до полутора радиусов маски. Три изображения показаны с общими
пределами отображения по референсу.

Настройки можно скачать в JSON. Мастер хранит последний предпросмотр
в браузере. Кнопка **Сгенерировать с этим светом** применяет изменённые
параметры ко всем сценам открытого прогона, сохраняя центры, маски, seed
и снимок разметки. Новый ZIP и профиль становятся текущим результатом
проекта. Исходный ZIP остаётся доступен по ссылке. Новый профиль используется
для обучения из мастера, а ручные значения сохраняются при перекалибровке
по предложениям модели. Кроп, общая шкала и переключатель зерна относятся
к предпросмотру.

## Сохранение проекта

Проекты доступны в выпадающем списке. Мастер сохраняет контуры, фон,
центры, просмотренные кропы и настройки генерации. Обновление вкладки
открывает тот же проект и этап. После перезапуска сервера доступны
сохранённые проекты и последние завершённые результаты. Незавершённую
генерацию после перезапуска сервера нужно запустить снова.

## Результат

Готовый ZIP можно скачать в браузере. Файлы также сохраняются в
`outputs/calibration_lab/<job>/run-<id>/`. Архив содержит:

- `example.tiff` — пример структурированного рендера.
- `scenes/*.npz` — два рендера каждой сцены с общими центрами и масками.
  `image` — базовый, `image_structured` — с локальной текстурой и засветкой.
- `profile.npz` — профиль для существующего генератора
  `python -m training.plane20.generate_median --profile … --output …`.
- `report.json` и JSON-разметка — параметры калибровки, seed и манифест сцен.

Для сомы с индексом `i` пиксели её маски лежат в
`instance_pixel_index[instance_offsets[i]:instance_offsets[i+1]]`.
Индекс пикселя разворачивается как `y, x = divmod(index, image.shape[1])`.
Обычные эллиптические маски могут пересекаться.

На шаге «Генерация» опция **Рост сом до контакта** запускает связный рост
от центров. Занятый пиксель останавливает соседний фронт в этом месте.
Снаружи рост ограничен разрешённой областью и 110% локального радиуса
исходного эллипса. В свободных местах за этой границей остаются просветы.
Для старого профиля тот же режим доступен через `--grow-somas`.

В сценах с ростом `growth_reach[i, k]` — расстояние от центра сомы до
первого выхода из её маски в долях исходного эллиптического радиуса,
где `k` идёт по 64 равномерным углам в координатах эллипса, начиная с
положительного направления большой оси. Маски в этом режиме не
пересекаются. Свечение деформируется по сглаженным радиусам. В оптическом
рендере свет соседей по-прежнему суммируется. Размеры эллипсов и шкала
радиальных профилей в отчёте относятся к геометрии перед ростом.
Текущий обучающий код также строит свои цели по исходным эллипсам.

После генерации мастер показывает первую структурированную сцену рядом
с реальной медианой и до четырёх пар кропов с одинаковыми координатами.
По умолчанию для всех превью используется одна шкала яркости
(P1–P99,5 реальной медианы). Переключатель P5–P95 нормирует каждое полное
изображение и каждый кроп по их собственным перцентилям. Он влияет только
на предпросмотр.

В разделе «Графики сравнения с реальной медианой» сравниваются рабочая
медиана, базовый и структурированный рендеры. В отчёте показаны:

- Медиана яркости фона и разброс его текстуры в полосах 1–3 и 3–7 px.
  Для текстуры используется отступ в семь шагов эрозии от края маски.
  Области с остатком меньше 16 пикселей пропускаются.
- Размеры, отношение осей, радиальные профили, контраст отдельных сом
  и разброс яркости по дугам.
- Плотность в полностью просмотренных кропах и доля центров с ближайшим
  соседом в пределах заданного радиуса. Для каждого радиуса учитываются
  центры с соответствующим отступом от краёв кропа.
- Локальный контраст P95–P5 в окнах 32×32, где область размещения занимает
  не меньше 75% площади, и автокорреляция после вычитания сглаживания
  с σ = 12 px. Корреляция считается в ткани и в размеченном фоне для
  горизонтальных и вертикальных сдвигов 1, 2, 4 и 8 px.
- Полудисперсия логарифма контраста сом по интервалам расстояния.
  Под графиком указано число реальных пар в каждом интервале.

Измерения относятся к данным калибровки. Используется до 16 равномерно
выбранных синтетических сцен и до 128 сом на сцену для статистик света
сом. Для новых стеков из как минимум четырёх выбранных страниц фоновый
график включает две половины и четыре смешанные подвыборки той же длины.
Старая запись без подвыборок и готовая 2D-медиана дают одну реальную
точку на область.
