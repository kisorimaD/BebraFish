# BebraFish — генерация fish4 Plane16

Команды в этом руководстве запускаются из корня репозитория.

Текущий отчёт по симулятору Plane20, формату данных и плану обучения:
[Симулятор сом Plane20 и план обучения сегментации](plane20_simulator_and_training.md).

Оставлен один рабочий режим: статические синтетические изображения и GT
всей сомы по сохранённой калибровке fish4 Plane16. Исходная запись,
сервер, обучение, PyTorch и Octave для запуска не нужны.

Python 3.10+:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python pipeline.py --output outputs/fish4 --count 8 --seed 20261031
```

Каталог результата должен быть новым. Одинаковый seed воспроизводит
одинаковый кадр в одинаковом численном окружении. Генерация работает на CPU.

Профиль `profiles/fish4_plane16/`: 1728×288 px, 0.576 мкм/px,
2419 клеток, sigma=3.214579 px, size CV=0.1, ring fraction=0.5,
eccentricity=0.08, ring center fill=0.25, optical blur=0.6 px.
Это последний завершённый профиль `fish4_plane16_smaller_v1`;
экспериментальные увеличения плотности ×1.5 и ×2 не включены.

Результат:

- `simcalc_plane16.npz`: `synthetic_images` и `synthetic_labels` (uint16),
  `synthetic_tissue_masks`, `synthetic_seeds`, `metadata_json`.
- `footprints/seedN.npz`: полные маски всех клеток, включая перекрытия.
  Пиксели клетки k, ID начиная с 1:
  `pixel_index[offsets[k-1]:offsets[k]]`; индексы C-order растра `shape_yx`.

GT включает тёмный центр сомы. Растр labels хранит одного владельца
пикселя; для полной информации об экземплярах используйте footprints.
Клетки синтетические: профиль не является разметкой реальных нейронов
или измерением их истинного числа. Модель шума эффективная, в ADU.
Диффузионная постобработка не применяется.

Код рендера и файл профиля проверяются по SHA-256 из `calibration.json`.
Остальные исторические поля этого JSON сохраняют происхождение калибровки;
указанные там серверные пути и скрипты подгонки для генерации не требуются.

Проверка:

```bash
python -m unittest discover -s tests -v
```

Ядра клеток: vendored SimCalc, commit
`0035c24f6deeb5218fba8e708fae91e04242e9e6`, с локальной поддержкой колец.
Лицензия сохранена в `simcalc_zebrafish_pipeline/vendor/SimCalc/LICENSE`.

## Пробная подгонка Plane 20

Новый `data/Plane_Aligned_20.tiff` содержит 1000 кадров uint16,
каждый **1376×320 (Y×X)**. Это другой размер, чем у старого
fish4 Plane16: исходный 288×1728, рабочий после транспонирования
1728×288. Физический масштаб нового TIFF не указан.

Отдельный исследовательский скрипт не меняет замороженный профиль:

```bash
python tools/fit_plane_frame.py --frame 500 --output outputs/plane20_trial
```

`--frame` — индекс с нуля (500 означает кадр №501). Скрипт оценивает
фон и эффективный шум по 16 соседним кадрам, строит сглаженные поля
ткани/яркости и выбирает sigma и долю колец из небольшой сетки по
дисперсиям в четырёх пространственных диапазонах. Число клеток
переносится из старого профиля пропорционально площади ткани; оно
не измерено в новых данных. Остальная морфология наследуется.

Результаты: `comparison.png` (одна шкала ADU; транспонирование только
для показа), `crops.png`, `diagnostics.png`, `report.json`, новый
`profile.npz`, `frame_fit.npz`, `synthetic.tiff`, `synthetic_labels.tiff`.
В NPZ сохраняются полный синтетический GT с перекрытиями и центры.
Это пробная статистическая подгонка одного кадра, не разметка реальных
нейронов и не проверенная новая производственная калибровка.

### Эксперимент с плотностью и соседством

```bash
python tools/compare_packing.py --fit outputs/plane20_trial --output outputs/plane20_packing
```

Сравнивает исходную расстановку с числом клеток ×2/×2.5 и с локально
более равномерной упаковкой (35 итераций взвешенной релаксации Ллойда).
Сохраняются карта плотности, размеры/форма ядер и целевой контраст из
пробной подгонки. В плотных вариантах свечение дополнительно нормируется
на локальное среднее, чтобы добавление клеток не пересвечивало ткань;
доля клеточной текстуры подбирается под прежний целевой контраст. Профиль
Plane16 и его проверяемый по хешу рендерер не меняются.

`packing_crops.png` и `packing_full.png` используют общую шкалу ADU.
В `report.json` — расстояния до ближайших центров, покрытие ткани сомами
и доля окружённых клеток. Последняя — геометрическая оценка: сосед
находится не дальше суммы эквивалентных радиусов масок +1 px, а максимальный
угловой промежуток между соседями меньше 180°. Это не оценка контактов
в реальной записи; маски в проекции могут перекрываться. Плотность ×2/×2.5
проверяет визуальную гипотезу, а не измеренное число реальных нейронов.

## Локальная разметка размеров нейронов

```bash
python tools/annotate_somas.py --open
```

Песочница открывается на `http://127.0.0.1:8765`: кропы кадра 500,
свободные контуры и полигоны всей сомы, правка вершин, масштаб/контраст,
пометки сомнительных и неполных клеток, отмена действий. Разметка
автоматически сохраняется на диск в `annotations/`, доступны JSON и CSV.
Размеры измеряются в исходных пикселях без предположений о мкм/px.
Инструкция и формат: [annotation_sandbox/README.md](../annotation_sandbox/README.md).

## Проверка масок модели на реальном кадре

```bash
python tools/review_somas.py --open
```

Soma Review показывает исходный кроп и предложенную маску рядом. Клавиши
**Y** и **N** сохраняют решение и открывают следующую карточку. В JSON
экспортируются исходные маски обеих моделей, решения и привязка к кадру.
[Инструкция и формат экспорта](../soma_review/README.md).

## Проба по размеченной морфологии Plane 20

После `tools/analyze_somas.py` и предыдущей пробы плотной упаковки:

```bash
python tools/generate_empirical_somas.py --output outputs/plane20_empirical
```

Каталог результата должен быть новым. Используются прежние центры из
`outputs/plane20_packing/variant_4.npz` и совместная равновероятная выборка
осей и угла из 98 полных размеченных сом. Поправки на смещение отбора нет.
Геометрия GT теперь задаётся заполненным эллипсом; тип свечения solid/ring
и заполненность центра не меняют его размер. Новый экспериментальный
рендерер поддерживает произвольный угол и разные главные оси ковариации.

В результате: uint16 `synthetic.tiff`, `labels.tiff`, полный `synthetic.npz`
с перекрывающимися footprints, центрами, параметрами эллипсов и номерами
исходных аннотаций; `report.json`, `full_comparison.png`,
`crop_comparison.png`, `geometry_check.png`. Старый профиль Plane16
не меняется. Карта ткани/плотности, область между полушариями и общие
деформации ещё не переоценены; фотометрия наследуется от прежней пробы.

## Параметрическая морфология и подгонка света оболочки

```bash
python tools/fit_soma_light.py --output outputs/my_shell_trial
```

Команда использует ранее полученные `outputs/soma_analysis/`,
`outputs/plane20_trial/` и `outputs/plane20_empirical/`. Каталог результата
должен быть новым. Размер выбирается из положительной нормали,
отношение осей минус один — из гамма-распределения, ориентация — из
осевого von Mises. Параметры берутся из анализа 98 полных аннотаций;
эмпирического ресэмплинга и поправки на смещение отбора нет.

Пользователь уточнил, что контур аннотации лежит примерно посередине
светящейся оболочки. Новый эффективный профиль света — гауссова
оболочка по эллиптическому радиусу, с независимой шириной и положением
пика; затем применяется прежнее оптическое размытие 0.6 px. Параметры
подбираются по радиальным профилям реальных клеток, с проверкой на
отложенной пространственной полосе. Визуализации сравнивают прежнюю
пробу, параметрическую геометрию со старым светом и новую оболочку.

`annotation_labels.tiff` и `labels` в NPZ соответствуют именно области,
ограниченной mid-shell контуром, включая тёмный центр. Это не оценённая
внешняя биологическая поверхность сомы. Полные перекрытия сохраняются
в sparse footprints. `report.json` описывает измеримые статистики,
параметры, отбор измеримых профилей и ограничения идентификации ширины.
Субпиксельная ширина ядра модели не равна физической толщине цитоплазмы.

## Агрегаты фильма, остаточное движение и GIF

python -m pip install -r requirements-analysis.txt

Диагностика Plane 20: точные mean/max/q90/median по всем кадрам,

должен быть новым; ROI диагностики настроены на геометрию Plane 20.

## Полуавтоматическая разметка областей заливкой

```bash
python tools/annotate_regions.py --open
```

Новый локальный **Region Lab** на `http://127.0.0.1:8766` открывает q90.
Каждая поставленная точка имеет собственный абсолютный порог ADU:
выбирается связная область `I <= T`, общая маска объединяет заливки.
Есть перемещение/масштаб, правка и отключение точек, отмена действий,
автосохранение отдельного JSON в `annotations/` и экспорт PNG.
TIFF/NPZ можно восстановить из JSON через `--export`.

Инструкция: [region_sandbox/README.md](../region_sandbox/README.md).
Разметка сом и существующий профиль симулятора остаются отдельными.

Region Lab работает на всём кадре. Для каждой точки можно нарисовать
свой ограничивающий полигон: заливка не может пересечь его границы.
Без полигона используется весь кадр. Порог каждой точки остаётся независимым.
После обновления перезапустите сервер и обновите вкладку.

Эксперимент с фоном из текущей ручной маски и аддитивной синтетикой:

```bash
python tools/generate_masked_background.py --output outputs/plane20_masked_background_new
```

Берётся среднее фильма только в размеченных областях без нейронов,
сглаживается и гармонически интерполируется на весь кадр. Затем добавляется
неотрицательное свечение синтетических сом; их контуры не пересекают маску.
Компоненты и сумма без/с шумом сохраняются отдельно. Первый результат и
ограничения: `outputs/plane20_masked_background/RESULTS.md`.

Исследование локальной яркости, направленности текстуры и шума Plane20:
`tools/diagnose_scene_realism.py`; эксперимент с амплитудами,
переменным эффективным размытием и коррелированным шумом:
`tools/try_heterogeneous_scene.py`.
Результаты: `outputs/plane20_realism_diagnostics_v2/RESULTS.md` и
`outputs/plane20_heterogeneous_trial_v2/RESULTS.md`. Это отдельные
эксперименты: оптическая PSF не идентифицирована, направленный вариант
пока не превосходит изотропный на отложенных местах.

Коррелированное усиление яркости целых клеток и контроль с перестановкой
того же массива усилений: `tools/try_correlated_cell_gain.py`.
Результат и статистика по расстоянию между сомами:
`outputs/plane20_correlated_gain/RESULTS.md`. В этом эксперименте
локальная нормировка заморожена до применения усилений, чтобы
не стирать создаваемые группы яркости. Форма оболочек не меняется.

Вариант с масштабом усиления ×1,75 (~28px), без изменения sigma усилений:
`outputs/plane20_correlated_gain_larger/RESULTS.md`.
Извлечение профилей свечения вдоль существующих контуров оболочек:
`tools/inspect_shell_angles.py`, результаты —
`outputs/plane20_shell_angles/RESULTS.md`. Новая разметка для этой пробы не нужна.

Проба гладкого неоднородного свечения вдоль периметра сом:
`tools/try_angular_shells.py`. Четыре уровня модуляции сохраняют
поле групповой яркости 28px, суммарную собственную эмиссию клеток,
их геометрию и полные GT-маски. Рисунки по периметру пока независимы
между клетками. Серия сравнения: `outputs/plane20_angular_shells/RESULTS.md`.

Выбранный medium (сила оболочки 0,50) с шумом, который зависит от
фактического освещения синтетики: `tools/refine_medium_noise.py`.
Квадратичная добавка эффективной дисперсии ослаблена до 25%,
с сохранением read floor и линейной части. Сам clean-сигнал не меняется.
Сравнения: `outputs/plane20_medium_noise/RESULTS.md`.

Утончение оболочки принятого medium на 15% при сохранении собственной
эмиссии клетки и той же реализации обновлённого шума:
`tools/try_thinner_medium.py`, результат —
`outputs/plane20_medium_thinner/RESULTS.md`.

Слепой тест «реальные данные или синтетика» с размерами кропов,
фильтром по маске исключения, статистикой и сохранением ответов:

```bash
python tools/crop_quiz.py --open
```

http://127.0.0.1:8767. По умолчанию кадр 500 и последняя синтетика
`plane20_medium_thinner`; случайные реальные кадры — `--random-frames`.
Инструкция: [crop_quiz/README.md](../crop_quiz/README.md).

Проверка контраста отдельно от амплитудно-нормированной структуры:
`tools/fit_contrast_sharpness.py`. Новый выбранный вариант усиливает
локальные перепады клеточного сигнала с коэффициентом 1,8, сохраняя
общую эмиссию. Отдельный контроль уменьшает PSF, но по структурным
метрикам он дальше от реальных данных и не выбран основным.
Результаты: `outputs/plane20_contrast_sharpness/RESULTS.md`.

Crop Quiz по умолчанию теперь использует этот вариант. Добавлен
диагностический режим P5–P95 по каждому кропу; общая шкала ADU
остаётся режимом по умолчанию. Обновлённый тест в текущей сессии:
http://127.0.0.1:8768; запуск — `python tools/crop_quiz.py --port 8768 --open`.
