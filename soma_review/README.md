# Soma Review · Plane20

## Очередь для медианы после фильтра

Для подготовленной сессии используйте:

```bash
python tools/review_somas.py \
  --input outputs/plane20_median_resolution/local.tiff --frame 0 \
  --session annotations/plane20_median_filtered_roi_review --port 8774
```

Адрес — [127.0.0.1:8774](http://127.0.0.1:8774/). Можно просматривать обе
модели или выбрать одну в меню «Проверять». Каждый ROI получает отдельное
решение. Совпавшие кандидаты двух моделей имеют общий `location_id` в экспорте.

- **Да / Y** — полная маска подходит по видимому внешнему контуру сомы,
  включая тёмный центр.
- **Нет сомы / N** — в этом ROI нет сомы. В экспорте `rejected` с причиной `no_soma`.
- **Плохая маска / M** — сома есть, маска требует исправления. В экспорте
  `rejected` с причиной `bad_mask`.
- **Неясно / U** — по этому кропу нельзя уверенно решить. В экспорте `uncertain`.

Сессия хранит решения отдельно от старой разметки. Экспорт включает исходные
индексы ROI, хеши наборов предсказаний, параметры фильтра, координаты и
точные маски. Для повторного создания сессии с другим именем используйте
`python tools/prepare_median_roi_review.py --session <новая_папка>`.
Подтверждение «Нет сомы» относится к проверяемому ROI. В соседних участках
того же кропа могут находиться клетки.

## Исходная сессия кадра 500

Песочница для проверки масок модели на реальном кадре 500 из
`Plane_Aligned_20.tiff`. Запуск подготовленной сессии из корня репозитория:

```bash
python tools/review_somas.py --open
```

Адрес — http://127.0.0.1:8767. Сервер запускается локально, а просмотр
использует исходные 16-битные пиксели без загрузки данных в браузерный сервис.
Для открытия сохранённой сессии нужны NumPy, SciPy и tifffile.
Инференс и TensorFlow при просмотре не запускаются.

## Просмотр и решения

- **Да / Y** — принять показанную маску целой сомы с тёмным центром.
  Целевая граница проходит примерно по середине светящейся оболочки.
- **Нет / N** — отклонить показанную маску. Причиной может быть и плохая
  граница у настоящей сомы.
- **← / →** — перейти к соседней карточке. **Без решения** — перейти к
  следующей непроверенной. Уже выставленное решение можно изменить или сбросить.
- Слева виден кроп исходного кадра, справа — тот же кроп с точной растровой
  маской. Размер поля и контраст меняют только отображение.
  Клик по обзору кадра открывает ближайшую карточку.
- При совпадении предложений двух моделей выберите нужную маску в списке
  **Маска**. Решение сохраняется для конкретного показанного варианта.
  Повторное решение в той же карточке заменяет предыдущее.
- Очередь чередует области кадра по сетке 64×64 px. В конец очереди
  отложены предложения вне прежней области предполагаемой ткани.
  В каждой из двух частей очереди карточки рядом с прежними ручными
  контурами идут после остальных. Метка «рядом есть контур» основана на
  расстоянии до центроида ≤2,5 px и служит подсказкой.

## Сохранение и дальнейший анализ

Используйте один сервер на папку сессии. После каждого решения сервер
атомарно обновляет `annotations/plane20_model_review_frame500/decisions.json`.
При перезапуске сессия продолжится с первой карточки без решения.
Файл `proposals.json` той же папки хранит исходные маски и параметры моделей.
Вручную размеченные файлы остаются отдельным источником.

**Экспорт JSON** скачивает один автономный `soma-review-export-v1`. Он содержит
имя TIFF, индекс и SHA-256 кадра, упорядоченный список карточек, варианты
масок, параметры и хеши чекпойнтов, решения и их время. Кадр в JSON задаётся
ссылкой через метаданные. Исходные интенсивности берутся из TIFF.
Для разбора принятой выборки:

```python
import json
from pathlib import Path

doc = json.loads(Path("soma-review.json").read_text())
for group in doc["proposals"]:
    decision = doc["decisions"].get(group["id"])
    if decision is None or decision["status"] != "accepted":
        continue
    mask = next(c for c in group["candidates"] if c["id"] == decision["candidate_id"])
    # mask["center_yx"] содержит центр в исходных координатах TIFF.
    # Для каждого [y, x0, x1] из mask["mask_runs_yx"]
    # пиксели маски в любом кадре фильма читаются как frame[y, x0:x1].
```

Оси в файле идут в порядке YX, индексы отсчитываются от нуля, правая граница
полосы исключается. На экране кадр транспонирован, как в Soma Lab.
Маски отдельных экземпляров хранятся независимо и могут перекрываться.
Принятые формы остаются модельными. Для оценки морфологии это выборка
одобренных предложений. Клетки, пропущенные обеими моделями, в очередь
не попадают, а «нет» характеризует предложенную маску.

## Подготовка другой сессии

Получите один или два файла `instances.npz` вместе с соседними `report.json`
через `python -m training.plane20.center_inference predict`. Отчёт текущего
предиктора содержит хеш исходных пикселей. Для детектора, дообученного
с денойзером, передайте путь к весам через `--denoiser`. Сессия проверяет
хеш кадра, включая случай инференса по одностраничной копии нужного кадра.

```bash
python tools/review_somas.py \
  --predictions outputs/plane20_real_review/normal_noisy/instances.npz \
    outputs/plane20_real_review/denoiser_finetune_center32/instances.npz \
  --prior annotations/Plane_Aligned_20_frame500_9b7fb43eb0f3.json \
  --support-profile outputs/plane20_masked_background/synthetic.npz \
  --session annotations/plane20_another_review --open
```

При импорте путь `--session` должен быть новым. Чтобы продолжить, уберите
`--predictions`, `--prior` и `--support-profile`, оставив тот же `--session`.
Для другого источника укажите те же `--input` и `--frame` при создании
и открытии сессии. Пара предложений образует одну карточку при
расстоянии между центрами ≤2,5 px и IoU масок ≥0,25. Прочие предложения
остаются отдельными карточками.
