# Soma Lab — локальная разметка размеров сом

Из корня репозитория:

```bash
python tools/annotate_somas.py --open
```

Открывается `http://127.0.0.1:8765`. Требуются только существующие Python
зависимости репозитория и современный браузер; Node нужен лишь для тестов.
Если автоматическое открытие не сработало, откройте URL вручную.
Остановка сервера — Ctrl+C. Статический `python -m http.server` не заменяет
этот сервер: он не поддерживает сохранение разметки.

По умолчанию загружается кадр с индексом 500 из `Plane_Aligned_20.tiff`.
Другой кадр: `python tools/annotate_somas.py --frame 300 --open`.
Другой TIFF: `--input /path/to/file.tiff`. Вход — двумерные страницы uint16.
Для каждой комбинации содержимого кадра и индекса создаётся отдельный
файл разметки. Используйте один запущенный разметчик для этого checkout.

## Что размечать

Внешний контур **всей сомы**, включая тёмный центр/ядро. Не отдельное
яркое кольцо. Каждый нейрон — отдельный экземпляр; перекрытия разрешены.
Выбирайте несколько участков с разной яркостью и видимым размером клеток,
включая сложные участки. В выбранном участке размечайте все различимые
сомы, а не только самые удобные или наиболее крупные.

Сеточные кропы покрывают разные части кадра без ручного отбора «хороших»
мест. Щелчок по обзору полного кадра добавляет свой кроп. На рисунке
горизонтальная ось соответствует исходной Y, вертикальная — исходной X.
Экспорт всегда использует исходные `[x,y]`, без ресайза TIFF.

Если граница неоднозначна, выберите «Сомнительная граница» и при желании
добавьте комментарий. Если сома обрезана, включите «Неполная сома».
Контуры у края текущего кропа автоматически получают этот флаг; его можно
изменить вручную. Для начального распределения размеров используем
`confidence=confident` и `truncated=false`. Остальные контуры сохраняются
для анализа сложных случаев. Для первой итерации достаточно порядка
50–100 надёжных полных сом из нескольких разных участков.

## Управление

- **F, Контур:** обвести с зажатой левой кнопкой; отпускание замыкает.
- **P, Полигон:** клики ставят точки, Enter или двойной клик замыкает.
- **V, Выбор:** выбрать клетку и перетаскивать вершины. Shift + клик
  по ребру вставляет вершину; Alt + клик по вершине удаляет её.
- **Esc:** отменить незавершённый контур. Backspace убирает точку полигона.
- **Delete:** удалить выбранную сому; действие можно отменить.
- **Ctrl/Cmd+Z:** отмена, **Ctrl/Cmd+Shift+Z:** возврат.
- **M, Рука:** перетаскивание изображения по X/Y, в том числе при увеличении.
- **Колесо:** масштаб; **пробел + перетаскивание:** временный сдвиг из любого инструмента.
- **Вписать:** вернуть исходный масштаб и центрирование кропа.
- **H:** скрыть/показать маски. Контраст влияет только на отображение.

## Сохранение и формат

Каждое изменение автоматически записывается в
`annotations/Plane_Aligned_20_frame500_<hash>.json`. Зелёный статус
«Сохранено на диск» подтверждает запись. При следующем запуске разметка
подхватывается автоматически. Перед началом новой серверной сессии
предыдущий файл дополнительно копируется в `.session-backup.json`.
Каталог `annotations/` и сгенерированные `assets/` исключены из Git.
В браузере также хранится резервная копия. При ошибке записи интерфейс
показывает предупреждение; JSON можно экспортировать вручную.

**Экспорт JSON** содержит контуры, атрибуты, кропы, hash исходного кадра
и измерения каждой сомы. **CSV размеров** содержит все экземпляры,
включая сомнительные и неполные; они выделяются соответствующими полями.
JSON можно импортировать обратно, в том числе в другом браузере, если
запущен тот же кадр. Импорт заменяет текущую разметку и доступен для отмены.

Поля координат `points_xy` задают вершины в исходной системе пиксельных
границ: X в `[0,width]`, Y в `[0,height]`; центр пикселя `[i,j]` расположен
в `[i+0.5,j+0.5]`. Многоточечные контуры хранятся независимо, без потери
перекрытий и без уменьшения до единственной raster label map.

Для каждого контура сохраняются площадь, периметр, эквивалентный диаметр,
большая/малая оси и направление эквивалентного по вторым моментам площади
эллипса, отношение осей, circularity и центроид. Оси не являются Feret-
диаметрами. Все размеры — в px/px², физический масштаб не предполагается.
Периметр и circularity зависят от аккуратности обводки. Это измерения
разметки, а не оценка истинного числа/форм всех клеток в ткани.

После разметки достаточно передать путь к локальному JSON: из него
можно собрать распределения размеров и форм и полный набор масок.

## Проверки

```bash
python -m unittest discover -s tests -v
node --test tests/test_soma_geometry.mjs
```

Проверяются исходные пиксели и координаты, сохранение/загрузка,
защита от подмены кадра и измерения известных фигур. Проверка реального
браузерного взаимодействия требуется отдельно, если браузер недоступен
в среде разработки.

## Уточнение протокола для существующих 100 клеток Plane 20

После разметки пользователь уточнил: контуры этой выборки проведены
примерно по середине светящейся оболочки. При анализе света они
трактуются как mid-shell contour; прежняя инструкция о внешнем крае
не описывает фактическую границу этих 100 аннотаций. Исходные контуры
сохранены. Если продолжаете эту выборку, сохраняйте ту же конвенцию
или явно отделите новую разметку внешней поверхности.
