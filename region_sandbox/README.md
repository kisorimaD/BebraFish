# Region Lab: заливка q90 с индивидуальными полигонами

Запуск из корня репозитория:

```bash
python tools/annotate_regions.py --open
```

Откроется http://127.0.0.1:8766. После обновления кода перезапустите
сервер и перезагрузите вкладку. Карта по умолчанию —
`outputs/plane20_movie_diagnostics/q90.tiff`.

## Работа

1. Поставьте точку инструментом **Точка (A)**. Она выбирает связную область
   исходных пикселей `I <= T`; стартовый порог — яркость точки +8 ADU.
2. Подберите её абсолютный порог справа. Порог независим для каждой точки.
3. Если заливка утекает, нажмите **Ограничить полигоном** для выбранной точки.
   Кликайте вершины допустимой области; **Enter** замыкает контур,
   **Backspace** убирает последнюю вершину, **Esc** отменяет рисование.
   Точка должна лежать внутри. Можно нарисовать новый контур той же кнопкой
   или удалить ограничение кнопкой **Убрать полигон**.

Работа идёт по всему кадру, без сетки кропов. Полигон ограничивает только
заливку своей точки. Порог продолжает работать внутри него: полигон сам
по себе не заполняется. Путь не может выйти наружу и вернуться с другой
стороны. Без полигона точка может заливать весь кадр. Общая маска —
объединение включённых заливок; поэтому другие точки могут заливать
пиксели за пределами полигона выбранной точки.

**V** выбирает и перетаскивает точки (в пределах собственного полигона).
**M** или **Пробел + мышь** перемещает вид, колесо масштабирует у курсора.
Клик по обзору центрирует вид на выбранном месте. По горизонтали на экране
исходная Y, по вертикали X; экспорт имеет исходную ориентацию TIFF.
**Delete** удаляет точку, **H** скрывает маску, **Ctrl/Cmd+Z** отменяет,
**Shift+Ctrl/Cmd+Z** возвращает действие. Контраст меняет только отображение.

## Сохранение и экспорт

Автосохранение — отдельный JSON в `annotations/`, формат `region-flood-v3`.
Каждая точка может содержать `polygon: [[x,y], ...]` с целыми исходными
индексами пикселей; граница включается по центрам пикселей. Полигоны,
пороги и точки входят в JSON и восстанавливаются при импорте.
Браузер хранит резервную копию в новом пространстве v3; старый кеш
версии с кропами не восстанавливается автоматически.

При запуске прежние v1/v2 документы переводятся в v3 без сетки;
перед переходом создаётся `.pre-polygons.json`. При импорте старого JSON
кропы также снимаются. CLI-экспорт старого JSON сохраняет его старый смысл.
Сервер отклоняет запись из старой вкладки: обновите страницу.
Перед каждой серверной сессией создаётся `.session-backup.json`.

**Экспорт точек** скачивает JSON; **Маска PNG** — общую маску в исходной
ориентации Y×X. Белое = выбранные области исключения; чёрное = неизвестно,
а не подтверждённые нейроны. Для TIFF/NPZ:

```bash
python tools/annotate_regions.py \
  --export annotations/regions_q90_72560cae13ef.json \
  --output outputs/regions_final
```

Каталог результата должен быть новым. Создаются `exclusion_mask.tiff`
(uint8 0/255), `exclusion_mask.npz` (bool + JSON) и `points.json`.
Hash карты проверяется. Исходный TIFF и разметка сом не изменяются.
Для другой двумерной карты используйте `--input /path/to/map.tiff`.
Расчёт в браузере выполняется в Worker, без внешних сервисов.

## Проверки

```bash
node --test tests/test_region_flood.mjs tests/test_region_worker.mjs tests/test_region_crops.mjs
python -m unittest discover -s tests -v
```

Проверяются пороги, связность 4/8, запрет обхода полигона снаружи,
независимость ограничений, сброс кеша при изменении полигона, совпадение
JS/SciPy для вогнутых и наклонных границ, сохранение и экспорт.
