# Данные для повторной отрисовки Plane20 со вспышками

- `scene_00000.npz` содержит исходную синтетическую сцену, центры и маски сом.
- `activity.npz` содержит полные трассы в порядке кадр × сома.
  `dff` хранит сэмплированную активность после оценки фона,
  `render_modulation` — фактически применённые изменения яркости.
  `donor_frames`, `previous_donor_frames` и `blend_weight` описывают
  выбор кадров и смешивание на границах временных окон.
  `diffuse_tile_changes` хранит крупномасштабную динамику фона.
- `assignments.csv` связывает синтетические сомы с донорскими ROI и
  группами. Амплитуда в последнем столбце измерена по `render_modulation`.
- `generation.json` содержит исходную калибровку сцены и параметры шума.
  `validation.json` содержит коэффициенты версии со вспышками и измерения
  на отложенных кадрах.
- `reference_median.tiff` содержит калибровочную матрицу Plane20.

Подключите базовый архив и установите зависимости из
`requirements-render.txt` по [основной инструкции](../../README.md).
Восстановить кадр в исходных единицах яркости можно из корня папки
`video_generator`.

```bash
python analysis/plane20_gcamp8f_response/calibrate_flash_dynamics.py \
  --source results/Plane20 \
  --replay-frame 2 \
  --output synthetic_frame_0002.tiff
```

Индексы кадров начинаются с нуля. Сохранённых массивов и профиля из
`plane20_synthetic.zip` достаточно для повторного рендера.
