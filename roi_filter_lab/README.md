# Plane20 · фильтр ROI

Из корня репозитория запустите:

```bash
python tools/roi_filter_lab.py
```

Откройте [ROI Lab](http://127.0.0.1:8772/). Лаборатория читает
зарегистрированную медиану и сохранённые предсказания пилота и Wide64.
Пороги применяются к уже рассчитанным кандидатам в браузере.

- Щёлкните по обзору, чтобы выбрать участок. Слева показан оригинал,
  справа тот же кроп с контурами. Шкала яркости одинакова в обоих окнах.
- Щёлкните по ROI и нажмите «Отметить как неверный». Shift + щелчок
  ставит или снимает отметку сразу. Повторный щелчок переключает
  перекрывающиеся ROI.
- Счётчики показывают, сколько отмеченных кандидатов всего,
  сколько отсечено и сколько остаётся активными. Щелчок по отметке
  в списке переносит просмотр к ROI.
- Отметки сохраняются в `annotations/plane20_roi_filter_marks.json`
  отдельно для каждого набора исходных предсказаний.

Пресет «Фильтр оболочки из проверки» отсекает окрестности с P95 ≤ 118 ADU,
а также ROI со score < 0,60 и медианным перепадом оболочки < 2 ADU.
Перепад измеряется относительно более яркой из двух областей в каждом
секторе — центра и ближайшего окружения. Отдельный выключенный по умолчанию
фильтр проверяет долю секторов с перепадом > 3 ADU.

Остановка сервера через Ctrl+C. Для другого порта используйте `--port`.
Для отдельного файла отметок используйте `--marks`.
