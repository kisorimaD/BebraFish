01 / ОБЛАСТЬ ИССЛЕДОВАНИЯ

Кропы кадра

Выберите участок. Обзор снизу позволяет добавить свой кроп.

Не только удобные клетки

Добавьте несколько участков с разной яркостью, размерами и сложными границами. В пределах кропа отмечайте все различимые сомы.

Обводите внешний контур всей сомы, включая тёмный центр. Не обводите только яркое кольцо.

Мышью: свободный контур с зажатой кнопкой. Полигон: точки по клику, Enter — замкнуть. Esc — отменить.

В режиме выбора перетаскивайте вершины. Для вставки вершины — Shift + клик по ребру, для удаления — Alt + клик по вершине. Delete удаляет выбранную клетку.

Колесо меняет масштаб. Инструмент «Рука» (M) или пробел + перетаскивание двигает изображение по X/Y. H скрывает маски. Ctrl/Cmd+Z — отмена, Shift+Ctrl/Cmd+Z — возврат.
