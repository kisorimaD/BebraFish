# Crop Quiz — отличить реальные кропы от синтетики

Запуск из корня репозитория:

```bash
python tools/crop_quiz.py --open
```

Адрес: http://127.0.0.1:8767. Нужны зависимости из `requirements.txt`;
Node и установка веб-пакетов для работы не требуются.

## Использование

- По умолчанию случайные кропы **96×96**, каждый источник выбирается
  независимо с вероятностью 50%. Ровно половина в короткой серии не гарантируется.
- **1** — реальные данные; **2** — синтетика. После ответа показываются
  правильный источник, координаты и статистика. **Enter** — следующий.
- Размеры можно менять независимо или выбрать квадратный пресет.
  Нажмите **Применить и показать новый**. Неотвеченный предыдущий кроп
  будет пропущен и в статистику не попадёт.
- Фильтр **Только кропы без пикселей маски исключения** включён по умолчанию.
  Все пиксели прямоугольника должны лежать вне маски; условие одинаково
  для обоих классов. Допустимые позиции вычисляются точно через интегральные
  суммы маски, затем позиция равномерно выбирается из этого множества.
  У текущей маски для 96×96 есть 29337 позиций, для 160×160 — 2294,
  для 192×192 — ни одной. Для невозможного размера выводится ошибка;
  уменьшите кроп или отключите фильтр.
- Масштаб 1× / 2× / 4× / вписать одинаков для обоих источников.
  Ширина на экране соответствует исходной Y, высота — исходной X.
  Интерполяция отображения pixelated; индивидуальной подстройки
  контраста по кропу нет.

Источник до ответа хранится на сервере. Клиент получает непрозрачный ID
и PNG с нейтральным URL. В режиме общей шкалы контраст задаётся единожды по 1–99,5 процентилям
реального кадра 500 и одинаков для обоих источников. В диагностическом
режиме P5–P95 каждый кроп нормируется отдельно одинаковым алгоритмом.
Это убирает подсказку по абсолютной яркости и диапазону, но не является
исправлением самой синтетики. В статистике и экспорте режимы разделены. Изображения имеют
одинаковое преобразование ADU в 8-битные уровни, ориентацию и формат.
Повторная отправка того же ответа не увеличивает счётчик.

## Данные по умолчанию

- Реальный: `data/Plane_Aligned_20.tiff`, кадр **500** (отсчёт с нуля),
  одиночная экспозиция, не q90 и не среднее.
- Синтетический: `outputs/plane20_contrast_sharpness/synthetic.tiff`:
  medium 0,50, поле усиления ~28px, ширина оболочки 0,306,
  обновлённый шум с квадратичной добавкой 25%; эффективный локальный
  контраст клеточного сигнала усилен в 1,8 раза с сохранением общей эмиссии.
- Маска: `outputs/plane20_masked_background/exclusion_mask.tiff` —
  снимок разметки, использованный для генерации. 255 означает исключение.
  Неразмеченный пиксель не гарантирует наличие нейронов; фильтр проверяет
  именно отсутствие выбранных областей без нейронов.

Можно выбирать случайный реальный кадр фильма в каждом вопросе:

```bash
python tools/crop_quiz.py --random-frames --open
```

Другой фиксированный кадр: `--frame 600`. Другой TIFF синтетики:
`--synthetic path/to/image.tiff`. Другая маска: `--mask path/to/mask.tiff`.
Размеры кадров и маски должны совпадать. Порт меняется через `--port`.
Сервер слушает только 127.0.0.1. Сервис не меняет исходные TIFF и аннотации.

## Статистика и сохранение

Ответы автоматически пишутся в отдельный файл каждой серверной сессии:
`outputs/crop_quiz/quiz_*.jsonl`. Есть кнопка **Экспорт результатов**
для JSON в браузере. В журнале сохраняются источники/хеши данных,
настройки контраста, правильный класс и ответ, координаты, размер,
фильтр, время и хеш исходного кропа. На перезагрузке страницы статистика
текущего сервера восстанавливается; настройки кропов помнит браузер.
При перезапуске сервера начинается новая сессия, прежние журналы остаются.

Это интерактивное сравнение одной синтетической сцены с реальными данными.
Кропы могут перекрываться; пользователь может запоминать места.
Процент ответов сам по себе не является оценкой качества на независимых
рыбах/фильмах. Изменения размеров и фильтра сохраняются для каждого ответа,
но сводная статистика интерфейса объединяет ответы текущей сессии.

## Проверки

```bash
python -m unittest discover -s tests -p test_crop_quiz.py -v
```

Проверяются точная маска и краевые положения, совпадение преобразования
интенсивности и ориентации, скрытая метка до ответа, раскрытие после,
идемпотентная запись, сохранение журнала, невозможные размеры и HTTP.

Обновлённая сессия в текущем эксперименте запущена на порту 8768,
чтобы оставить предыдущие ответы отдельно:

```bash
python tools/crop_quiz.py --port 8768 --open
```

Метрики контраста/текстуры и контролируемое сравнение уменьшения PSF:
`outputs/plane20_contrast_sharpness/RESULTS.md`. Статистики по форме
текстуры пока различаются — совпадения диапазона яркости недостаточно.
