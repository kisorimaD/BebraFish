# Генератор синтетической кальциевой съёмки zebrafish

Генератор строит синтетическую съёмку без движения по выровненным TIFF
одного набора. Он извлекает ряды кальциевой активности и формирует общий
банк для повторного сэмплирования. Профиль активности и параметры
рендера подбираются отдельно для каждой выходной плоскости.
Для сегментации новых TIFF нужны совместимые веса.

## Подключение исходного Plane20 Synthetic

Для запуска нужны оба архива. Распакуйте этот архив и зайдите в его
корневую папку. Подключите исходный `plane20_synthetic.zip` и примените
изменения генератора. В Linux нужны команды `unzip` и `patch`.

```bash
unzip -q /path/to/plane20_synthetic.zip -d plane20_synthetic
patch -p1 < plane20_synthetic.patch
```

Данные для повторной отрисовки итоговой синтетики находятся в
[results/Plane20](results/Plane20/README.md). Там же есть пример
восстановления отдельного кадра.

## Установка

Среда для этого комплекта — Linux x86-64 и Python 3.11. Запустите команды
из корневой папки распакованного архива.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-render.txt
```

Для сегментации новых TIFF дополнительно установите зависимости
через `python -m pip install -r requirements.txt`.

Генерация и инференс выполняются на CPU. Для отдельных вариантов
сжатия TIFF может понадобиться `imagecodecs`, совместимый с NumPy 1.26.
Если `imageio-ffmpeg` не находит свой FFmpeg, можно указать
путь к установленному бинарнику через `IMAGEIO_FFMPEG_EXE`.

## Запуск

Входные данные — минимум две выровненные плоскости с именами
`Plane20.tif` или `Plane_Aligned_20.tiff`. Ожидаются 16-битные
одноканальные TIFF-стеки с одним кадром на страницу, одинаковой формой
кадра и одинаковым числом кадров. Минимум 100 кадров на плоскость.
Для подгонки нужно достаточно обнаруживаемых сом как в опорной
плоскости, так и в донорских.

```bash
python analysis/plane20_gcamp8f_response/run_dataset.py \
  --input /path/to/aligned-tiffs \
  --all-planes \
  --checkpoint /path/to/center-mask-checkpoint \
  --output ./synthetic_run
```

По умолчанию читаются все подходящие TIFF. Для поднабора используйте
`--planes 19 20 21`. В режиме `--all-planes` каждая выходная плоскость
может брать доноров из любой плоскости общего банка, включая свою.
Для заданного seed опорный порядок временных окон общий. Выбор доноров
и согласование активности выполняются по каждой плоскости отдельно.
Для генерации одной плоскости укажите `--reference-plane 20` вместо
`--all-planes`. В этом режиме доноров берут из остальных плоскостей.

Готовые маски одной плоскости можно загрузить через `--scene` и
`--profile`. Для нескольких плоскостей передайте `--geometry-dir`.
Внутри этой папки ожидаются `plane_N/scene/scene_00000.npz` и
`plane_N/profile.npz` для каждой выбранной плоскости.
При генерации новых масок `--cells 450` ограничивает их число
на плоскость.

Передайте `--fps` с частотой кадров TIFF, если она известна. Иначе для
выбора кадров используется 12,5 кадра/с. Опция `--seed` задаёт
воспроизводимый рендер, а `--activity-seeds 27 63 105` — варианты
выборки рядов. Первый вариант используется для калибровки рендера.
Повтор с теми же аргументами и `--resume` продолжает незавершённый запуск.

Передайте через `--checkpoint` папку с файлами `weights_best.h5` и
`model_config.json` от совместимой модели `plane20-center-mask-v1`.
При необходимости укажите `--model-code` и `--segment-python`.
При переходе на другую оптику или масштаб просмотрите маски в `per_plane/`.

## Проверка вариантов

Основной запуск включает согласование всплесков активности и
калибровку яркости, рассеянного фона и зернистости. Для других выборок
можно повторно использовать параметры рендера и сравнить статистики
готовых кадров на тех же временных блоках.

```bash
python analysis/plane20_gcamp8f_response/check_video_variants.py \
  --run ./synthetic_run/planes/plane_20
```

При запуске с `--reference-plane` передайте корневую папку результата
в `--run`. Проверка сохраняет GIF вариантов и сводную таблицу
`video_variants/comparison.csv` для свежей калибровки.

## Результаты

- `per_plane/` содержит центры, маски и извлечённые трассы.
- `foreground/trace_bank.npz` содержит отфильтрованный банк трасс.

Результаты для каждой плоскости находятся в `planes/plane_N/`
или в корневой папке одноплоскостного запуска.

- `profile.npz` и `scene/scene_00000.npz` описывают профиль и маски
  при генерации новой сцены. Путь к загруженной сцене указан в
  `profile_summary.json`.
- `activity_resamples_coordinated/` содержит полные ряды всех выборок
  и индексы их доноров. В `report/activity.npz` также сохранены
  фактически применённые изменения яркости и фона.
- `optical_model/` содержит параметры оптики и таблицу назначений.
- `report/validation.json` содержит метрики активности и фотометрии.
  В `paper_figures/` лежат графики сравнения по этим статистикам.
- В `report/real_vs_synthetic.gif` реальная запись показана сверху,
  синтетика снизу, обе на общей шкале. `signal_and_background.gif`
  дополнительно показывает сигнал сом и фон с шумом. GIF сохраняются
  при 3 кадрах/с и длятся до минуты.

Для повторного рендера архивного примера используйте
[инструкцию Plane20](results/Plane20/README.md).
